# CryptoTrada — Trading Intelligence Platform

## Overview
Multi-agent cryptocurrency trading platform with 4 concurrent strategies:
- Auto-Trend: Multi-coin trend-following with ATR risk management
- XRP Swing: 3-layer macro/tech/trigger engine
- SOL Swing: Breakout + mean-reversion specialist
- LINK Swing: Midpoint trend strategy

## Deployment
Uses Dockerfile for containerized deployment. PostgreSQL database required.
